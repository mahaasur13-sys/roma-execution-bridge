How to use the Decision AI Assistant

🚀 Quick Start

  1. Click the neon chat button ✦ in the bottom-right corner.
  2. On first launch, enter your name.
  3. Write in plain English or Russian — both are supported.

💬 Example Commands

"Submit the task python train.py on GPU""Show my latest jobs""Which workers are currently free?""How much have I spent so far?""Cancel job abc-123"

⌨️ Useful Buttons

  • Enter — send message
  • Shift+Enter — new line
  • Stop — stop generation
  • ⌫ — clear history

To let the AI perform actions on your behalf, save your key:

localStorage.setItem("roma_api_key", "YOUR_KEY")

  • Best price/performance ratio

API Reference

System & Health

GET /health System health
GET /redoc API documentation (ReDoc)
GET /docs Swagger UI
GET /openapi.json OpenAPI schema

Job Management

POST /api/v1/jobs Submit a new job
GET /api/v1/jobs List all jobs
GET /api/v1/jobs/{job_id} Get job status
DELETE /api/v1/jobs/{job_id} Cancel a job

Tenants & Billing

POST /api/v1/tenants Register a new tenant
GET /api/v1/tenants/{tenant_id} Get tenant details
GET /api/v1/tenants/{tenant_id}/usage Get usage report
GET /api/v1/tenants/{tenant_id}/billing Get billing summary

Workers & GPU Fleet

GET /api/v1/workers List available workers
GET /api/v1/workers/{worker_id} Get worker status
GET /api/v1/workers/{worker_id}/metrics Live GPU metrics
