# ROMA Beta — Onboarding Checklist

Добро пожаловать в закрытую бету ROMA Execution Bridge! 🚀

Следуйте этому чеклисту, чтобы быстро начать.

## Шаг 1: Регистрация (2 минуты)

Вы получили инвайт-код на email. Зарегистрируйтесь:

1. Перейдите на `/auth/signup`
2. Заполните: email, пароль (≥8 символов), имя
3. Вставьте инвайт-код из письма
4. Нажмите «Sign Up»

## Шаг 2: Подтверждение email (1 минута)

1. Проверьте почту — письмо от ROMA с темой «Verify your email»
2. Нажмите ссылку «Verify Email» в письме
3. Если письмо не пришло — проверьте спам. Повторная отправка через `/auth/resend-verification`

## Шаг 3: Первая задача (3 минуты)

После верификации ваш API-ключ активирован. Отправьте тестовую задачу:

```bash
curl -X POST http://localhost:8900/submit \
  -H "Content-Type: application/json" \
  -H "X-API-Key: ваш-api-ключ" \
  -d '{"task":"echo Hello ROMA!","gpu_required":false,"priority":5,"execution_mode":"k8s_job","backend":"local"}'
```

Ожидаемый ответ: `{"status": "queued", "job_id": "..."}`

## Шаг 4: Проверка баланса (1 минута)

```bash
curl http://localhost:8900/billing/balance \
  -H "X-API-Key: ваш-api-ключ"
```

Результат покажет ваш план, баланс и лимиты.

## Шаг 5: Исследование API (5 минут)

- **Документация:** `http://localhost:8900/redoc`
- **Health:** `curl /health`
- **Мои задачи:** `curl /jobs -H "X-API-Key: ..."`
- **Статус задачи:** `curl /status/{job_id} -H "X-API-Key: ..."`

## Шаг 6: Фидбек (когда будет время)

Расскажите о вашем опыте:

```bash
curl -X POST /feedback \
  -H "Content-Type: application/json" \
  -d '{"rating":4,"liked":"Простая регистрация","improvement":"Нужны GPU-воркеры","bug":"Ошибка при cancel"}'
```

Или через форму на `/beta`.

## Часто задаваемые вопросы

### Q: Мой API-ключ не работает (401)
**A:** Проверьте, что email подтверждён (письмо со ссылкой verify). Без подтверждения ключ не активен.

### Q: Submit возвращает 402 (spend-cap)
**A:** Вы превысили лимит расходов ($5 в бете). Свяжитесь с нами для увеличения.

### Q: Где взять API-ключ?
**A:** Он в ответе после верификации email. Также показан в письме-подтверждении.

### Q: Что за BETA_MODE?
**A:** Во время беты действуют ограничения: только по инвайтам, макс. 20 пользователей, spend-cap $5.
