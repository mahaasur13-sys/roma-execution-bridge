# Онбординг бета-тестера ROMA

## Шаг 1. Регистрация
1. Перейди по пригласительной ссылке
2. Зарегистрируйся и подтверди email

## Шаг 2. Пополнение баланса
1. Зайди в Dashboard
2. Пополни баланс (минимум $5–10)
3. Дождись появления средств

## Шаг 3. Отправка первой задачи
Используй этот минимальный пример:

```bash
curl -X POST https://roma-execution-bridge-asurdev.zocomputer.io/submit \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"task": "nvidia-smi", "gpu_required": true}'
```

## Шаг 4. Отслеживание задачи
- Смотри статус в Dashboard
- Или используй `GET /status/{job_id}`

## Шаг 5. Проверка списания
После завершения задачи проверь:
- Уменьшился ли баланс
- Появилась ли запись в Usage

## Что делать, если что-то пошло не так
Напиши нам в Telegram / Discord / на email и приложи:
- `job_id`
- Время отправки
- Скриншот ошибки
