## Обнаруженный баг и исправление

### `/stats/daily` → 500 Internal Server Error

**Причина:** `from starlette.responses import Response` (только `Response`), а код `/stats/daily` использует `JSONResponse` (не импортирован).

**Исправление (применено):** `file main.py`, строка 23:
```python
# Было:
from starlette.responses import Response
# Стало:
from starlette.responses import JSONResponse, Response
```

После исправления эндпоинт корректно возвращает 401 при отсутствии API-ключа.

1. **Производительность отличная.** p95 = 95ms при 100 VUs — API выдерживает ~1 200 req/s без деградации.
2. **p99 = 158ms** — даже на хвосте распределения задержка в пределах нормы.
3. **Нет реальных ошибок.** Все 10 эндпоинтов отработали корректно:
   - 5 публичных → 200
   - 4 защищённых → 401 (как и ожидалось)

4. **Rate limiting не срабатывал** — при 1 229 req/s slowapi не активировал ограничения (пороги выше текущей нагрузки).
5. **Сетевая пропускная способность:** 860 MB получено / 30 MB отправлено — норма для данных объёмов.
