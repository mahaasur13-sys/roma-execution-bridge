# ROMA Beta Playbook

## Цель беты
Проверить полный цикл: регистрация → пополнение → отправка GPU-задачи → выполнение на Vast.ai → биллинг → отображение usage.

## Этапы проведения беты

### Этап 1. Закрытая бета (первые 15–25 человек)
- Только по инвайтам
- Ручной онбординг
- Ежедневный мониторинг

### Этап 2. Расширенная бета (50–100 человек)
- Открываем больше инвайтов
- Собираем структурированный фидбек

## Что говорить пользователям

**Короткое позиционирование:**
«ROMA — это единый API и биллинг для GPU. Ты отправляешь задачу, мы выполняем её на реальных GPU и списываем деньги по факту использования.»

**Важные правила для бета-тестеров:**
- Пока платформа в бете — возможны сбои и задержки
- Не запускайте дорогие и долгие задачи
- Сообщайте о любых ошибках сразу

## Ключевые метрики, которые нужно смотреть каждый день

1. Количество успешных GPU-job
2. Процент failed / timeout job
3. Среднее время от submit до completed
4. Количество ошибок биллинга (списание не произошло)
5. Количество пользователей, которые пополнили баланс
6. Utilization и ошибки со стороны Vast.ai

## Как обрабатывать ошибки

| Ошибка                        | Что делать                              | Что отвечать пользователю                     |
|------------------------------|-----------------------------------------|-----------------------------------------------|
| Job завис / timeout          | Проверить логи + Vast.ai инстанс        | «Задача превысила лимит времени, мы уже смотрим» |
| Не списались деньги          | Проверить ledger_entries                | «Проверяем биллинг, вернём/исправим вручную» |
| CUDA / image error           | Сменить дефолтный image                 | «Проблема с образом, уже исправляем»         |
| Пользователь не может submit | Проверить spend_cap и баланс            | «Проверьте баланс и лимиты в дашборде»       |

## Ежедневный ритуал бета-менеджера
1. Проверить failed jobs за последние 24 часа
2. Ответить на все сообщения пользователей
3. Записать повторяющиеся проблемы
4. Обновить статус в BETA_PLAYBOOK (что исправлено)
